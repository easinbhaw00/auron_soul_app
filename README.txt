AURON SOUL — Classic Dark/Light Starter

Included:
- index.html: responsive AI workspace interface
- logo-light.png / logo-dark.png: monochrome logo for dark and light themes
- icon.png: app/PWA icon
- manifest.json and service-worker.js

Open index.html in Chrome to preview the interface. For PWA installation and service worker behavior, publish through HTTPS (for example GitHub Pages).

Important: This is still a front-end starter. Chat replies are demo/template responses until a real AI provider is connected through a secure backend. Do not put private API keys in index.html. File selection, local notes/history, and feedback are local-only unless a backend is added.

NEW: Real AI is supported. Read SETUP-BN.txt (Bangla) and deploy backend/worker.js on Cloudflare Workers.
